java fundamental

Keywords:
In Java, keywords are predefined, reserved words that have specific meanings to the Java compiler and cannot be used as identifiers (e.g., variable names, method names, class names)

identifiers:
Identifiers in Java are names used to identify various programming elements such as classes, methods, variables, packages, and interfaces. They are essential for uniquely identifying and referencing these components within a Java program.

Literlas:
In Java, literals are fixed values represented directly within the source code of a program. They are constant values that are assigned to variables or used in expressions, and they cannot be changed during program execution.

Array:
In Java, an array is a fundamental data structure used to store a fixed-size, sequential collection of elements of the same data type. Arrays are objects in Java, allowing them to store both primitive data types (like int, double, boolean) and reference types (like String or custom objects)22
